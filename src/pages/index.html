What is Avarok Cybersecurity?

Avarok Cybersecurity is a software company that builds post-quantum security and infrastructure in Rust. Its foundation is the Citadel Protocol, an open-source networking SDK whose key exchange uses post-quantum key encapsulation (Kyber by default, with NTRU as an option) under a multi-layered ratchet, and whose session-layer design is covered by US patent 12224993. Every product in the family publishes its source on GitHub.

  • Post-quantum by default

    Citadel sessions agree keys through post-quantum KEMs and re-key per message, with a perfect-forward-secrecy mode and a best-effort mode for throughput.

  • Rust from the protocol up

    The Citadel Protocol is written in safe Rust on Tokio; Atlas is pure Rust and CUDA; LatticeDB and Citadel Docs are pure Rust compiled to WebAssembly.

  • Direct between people

    Built-in NAT traversal lets Citadel applications connect peers directly, so Citadel Workspace carries messages, files and calls over an encrypted peer channel instead of through a media server.

  • Open source

    The SDK is MIT or Apache-2.0; the applications are AGPL-3.0, MIT or Apache-2.0. See every open-source project.
