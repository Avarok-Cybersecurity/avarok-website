Open-source projects from Avarok

What is LatticeDB?

LatticeDB is a hybrid graph and vector database written in pure Rust. It compiles to WebAssembly and runs in the browser with no backend, which makes it a database for AI applications that keep their data on the user's device. Read the LatticeDB documentation or install lattice-db from crates.io.

What is Citadel Docs?

Citadel Docs is the document editor core for Citadel Workspace, in pure Rust compiled to WebAssembly: a document model, pagination and layout, and conversion to and from DOCX, PDF, Markdown and plain text. Its core crates do no I/O of their own.
