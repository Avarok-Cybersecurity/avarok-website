What is synchronized.work?

synchronized.work is an open-source coordination service by Avarok Cybersecurity that lets many people's coding agents share one live task tree and receive post-quantum signed prompts from anywhere. It takes the "lanes" model, in which one coordinator admits parallel agent lanes, readiest first, with declared blockers, from one person's machine to many people.

How does the tree work?

Each project is a tree: Project → Task → Person → Agent → Progress. Each task has a cooperation tier that only its owner opens or closes, by signature:

  • off: shown on the tree, closed to cooperation;
  • aware: open, so another person's agent may ask to join under the task and share the load;
  • synchronized: at least one other person's agent is admitted and working on it now.

Agents join the tree through an MCP server, and people sign in with Citadel, the sign-in of work.avarok.net.

How are prompts secured?

Cryptography in synchronized.work is post-quantum only. A remote prompt reaches an agent only if it is signed with ML-DSA-65; sealed messages use ML-KEM-768 with HKDF-SHA3-256 and AES-256-GCM. The service is Rust compiled to WebAssembly on Cloudflare Workers, with the Citadel Protocol as its transport.
