Citadel Workspace: post-quantum, peer-to-peer collaboration

What does Citadel Workspace do?

Citadel Workspace gives a team messaging, calls, file sharing and shared documents in one place, with every message, file and call encrypted end to end using post-quantum cryptography. Traffic travels directly between people rather than through a server that could read it.

  • Messaging: direct and group conversations; messages sent while someone is offline are held and delivered when they return.
  • Audio and video calls: one-to-one and group, encoded in the browser and carried over the same encrypted peer channel, with no SFU, no TURN server and no third party in the media path.
  • File transfer: files go straight to the people in the conversation, without being uploaded to storage in between.
  • Live documents: several people editing at once, with changes appearing as they type.
  • Workspaces, offices and rooms: a structure teams can map onto how they work, with permissions that inherit downward.
  • Installable: a PWA that installs to the desktop or home screen.

How is Citadel Workspace built?

The web app (React and WebAssembly) talks over a localhost-only WebSocket to the Citadel Agent, a local service on the person's own machine that owns their Citadel Protocol connections:

  • reliable Citadel peer-to-peer channels for chat, signalling and file transfer;
  • datagram peer-to-peer channels for audio and video frames;
  • a client-to-server connection to the workspace server, which stores structure and membership and never sees message contents, file contents or media.

Media is encoded and decoded in the browser with WebCodecs, so calls use the platform's hardware encoders; the protocol carries opaque encrypted frames.

How do I start using Citadel Workspace?

  1. Download and run the Citadel Agent for macOS, Linux or Windows.
  2. Open work.avarok.net and create a workspace, or sign in to one you belong to.
  3. Install it as an app from the browser if you want it on your desktop or home screen.
