What does the Citadel Agent do?

The Citadel Agent (citadeld) is a local daemon that manages the lifecycle of secure connections for applications on the same machine. It sits between those apps (command-line, desktop or web) and the Citadel Protocol SDK, and exposes a lightweight interface over local sockets and WebSocket. Apps send it requests; the agent holds the encrypted tunnels to servers and the peer-to-peer channels to other people.

Because one agent multiplexes every session on the machine, several local apps can use the Citadel Protocol at once without each embedding the SDK or managing connection state. Citadel Workspace runs on it: the web app connects to the agent over localhost only.

How do I verify a download?

Each release is built and attested by GitHub Actions. With the GitHub CLI installed, check that a file is the one the release workflow built:

gh attestation verify Citadel-Agent.dmg --repo Avarok-Cybersecurity/citadel-workspace

Every file is also published beside a .sha256 checksum. Compute the file's SHA-256 and compare it with that file on the release page:

macOS
shasum -a 256 Citadel-Agent.dmg
Linux
sha256sum citadel-agent-linux-x64.deb
Windows (PowerShell)
Get-FileHash -Algorithm SHA256 Citadel-Agent-x64.msi
